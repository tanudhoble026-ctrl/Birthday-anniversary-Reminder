# Birthday & Anniversary Pal

Build a simple, clean, responsive web application based ONLY on the following requirements. Do not add any extra features, pages, sections, or functionality that are not mentioned here.

PROJECT: Birthday & Anniversary Reminder

Requirements:

1. The application should allow the user to save a person's:

   - Name

   - Birthday date

   - Gift budget

2. Display all saved birthdays in a list.

3. Calculate how many days are left until each person's next birthday.

4. Sort the birthday list so that the nearest upcoming birthday appears at the top.

5. If the birthday is today:

   - Show a special birthday message.

   - Display the person's name in BIG LETTERS.

   - Clearly indicate that it is their birthday today.

6. Show the person's age they are turning on their next birthday.

7. Display dates in:

   - Month / Day / Year format.

8. If a person's birthday has already passed this year:

   - Calculate the next birthday for the following year.

   - Show the number of days remaining until that birthday.

9. Add anniversary reminders using the same concept:

   - Save anniversary date.

   - Calculate days remaining.

   - If the anniversary has already passed this year, use next year's date.

   - Show the anniversary date in Month / Day / Year format.

10. Show the total gift budget for all saved reminders.

11. Keep the design minimal, clean, and easy to understand.

12. The application must work correctly with today's date and automatically update:

   - Days remaining

   - Birthday status

   - Age being turned

   - Next year's date when the current year's date has passed

Build the complete working website with the required UI and functionality. Do not add anything beyond these requirements.
